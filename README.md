# 💈 CERBERO INSUMOS — Tienda online

**Todo lo que tu barbería necesita.** Tienda web para un emprendimiento de insumos de barbería: máquinas de corte, afeitado, styling y descartables, seleccionados por un barbero profesional.

## Cómo funciona

Es una tienda **estática** (sin servidor ni costos mensuales), pensada para emprendimientos que venden por WhatsApp:

- Catálogo con **buscador** y **filtros por categoría**.
- **Carrito de pedido** en el navegador: el cliente suma productos y cantidades.
- Al confirmar, el pedido completo se envía como mensaje al **WhatsApp del negocio**, donde se cierran pago y envío.

## Características

- Diseño oscuro mate (gris/negro), fiel a la identidad de la marca.
- 100% adaptable a celular.
- Catálogo fácil de ampliar: los productos se cargan en una lista simple dentro del código.
- Sin dependencias ni frameworks: HTML, CSS y JavaScript puro.

## Agregar un producto

Dentro de `index.html`, en la lista `PRODUCTOS`, se copia una línea y se cambian nombre, categoría, precio, foto y descripción. El archivo incluye una guía paso a paso en comentarios.
